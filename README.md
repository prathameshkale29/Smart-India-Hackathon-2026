# Smart India Hackathon 2026

## Overview

This project is built with TanStack Start, React 19, TypeScript, and Tailwind CSS.

## Getting Started

### Prerequisites

- Node.js (v20+)
- npm, pnpm, or bun

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```

## Tech Stack

- **Framework**: TanStack Start & TanStack Router
- **UI & Components**: React 19, Radix UI, Tailwind CSS v4, Lucide Icons
- **State & Data Fetching**: TanStack Query
- **Tooling**: Vite, TypeScript, ESLint, Prettier
